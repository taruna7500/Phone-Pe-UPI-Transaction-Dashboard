# Phone-Pe-UPI-Transaction-Dashboard
Excel Analyzed 5,02,887 transactions worth ₹44.25 crore, with 91% successful and 7% failed. Tracked ₹35 lakh in cashback and 17,089 suspected fraud cases (3.4%). PhonePe led app usage at 50%, Built interactive views by app, bank, state, age group, hour, city, gender, and merchant category using PivotTables, PivotCharts, and slicers.
